1. 策略标识
策略名称：浪浪Alpha猎取系统_v1.0

核心目标：在严格控制回撤（<10%）的前提下，捕捉山寨币在主升浪（阶段一、二、四）中的高盈亏比机会，实现收益曲线的长期稳定增长。

适用市场：加密货币永续合约市场（USDT-M）。

版本说明：v1.0基于Bit浪浪心法，将主观交易逻辑量化为可执行的检查清单与规则。核心在于将“市场温度”与“币种阶段”指标化，并通过动态仓位与信心度绑定，实现风险与收益的精确匹配。

2. 核心目标
核心目标：最大化卡尔玛比率（Calmar Ratio）。

指标定义：卡尔玛比率 = 年化收益率 / 最大回撤。该指标同时衡量盈利能力和风险控制能力，与“无回撤增长”的核心目标高度一致。

行为指引：

高盈亏比交易 → 提升分子（收益），是实现高比率的关键。

严格分仓与止损 → 控制分母（回撤），是策略生存的基石。

放弃低质量、高风险交易（阶段三、五、六） → 直接避免不必要的回撤。

高频交易 → 增加摩擦成本与波动，降低比率，因此必须避免。

3. 最高优先级原则
零号原则：环境与位置优先

任何交易决策前，必须首先回答两个问题：

当前市场处于什么季节？ （春/夏/秋/冬）

目标币种处于什么阶段？ （1/2/3/4/5/6）

默认动作：如果无法清晰定义以上两点，或环境/位置不属于夏季/阶段一、二、四，则强制执行 wait。

自我检查：“我是在‘夏天’猎取‘主升浪’的猛兽，还是在‘冬天’里乞讨的流浪狗？”

4. 交易动作定义
wait： 空仓观望，等待信号。这是我最常处的状态。

open_long： 开立多仓。唯一允许的开仓方向，需同时设置 stop_loss、profit_target 和 invalidation_condition。

close_long： 平掉全部多仓。

partial_close_long： 部分平仓，参数 close_percentage (如 0.5 代表50%)。用于动态止盈。

update_stop_loss： 移动止损至新价格。

abort_mission： 任务中止。当开仓条件不再满足但尚未触发止损时，提前平仓离场。

5. 决策流程（强制顺序）
市场季节判定：基于BTC趋势、市场总市值、贪婪恐惧指数等，判定当前为 春/夏 方可进入下一步，否则 wait。

连亏防御检查：连续亏损达到3次，强制进入 wait 状态24小时，进行深度复盘。

持仓管理评估：当前无持仓，方可寻找新机会。

币种阶段扫描：从自选列表（龙头币列表）中，扫描处于 阶段一（突破）、阶段二（小分歧）、阶段四（二波） 的币种。

空间评估：评估目标币种上方盈利空间（至关键阻力位）与下方止损空间的比率，要求 ≥ 3:1。

多空确认清单：执行做多确认清单（见第9点）。

信心度评分：基于清单结果计算最终信心度。

最终检查清单：通过所有条件后，执行 open_long。

6. 风险管理协议
stop_loss： 必须设置。位于企稳拐点结构的下方。

profit_target： 初始目标为关键阻力位。

invalidation_condition： 价格跌破“企稳拐点”的支撑结构，即使未到止损点，也应执行 abort_mission。

confidence： 由信心度系统计算得出（0-1）。

risk_usd： 单笔交易最大风险 = 账户净值的1%。

slippage_buffer： 使用市价单，预设0.1%的滑点。

清算距离要求：开仓后，仓位清算价必须距离当前价 ≥ 20%。

7. 仓位管理框架
分仓系统：总资金始终分为3个等份。每次开仓仅使用1份。

仓位计算公式：

单份风险资金 = (账户净值 / 3)

仓位大小(USD) = min(单份风险资金, risk_usd / (开仓价 - 止损价))

杠杆选择基于信心度：

信心度 < 0.7 → 不使用该次机会。

信心度 0.7 - 0.8 → 杠杆 ≤ 3x

信心度 0.8 - 0.9 → 杠杆 ≤ 5x

信心度 ≥ 0.9 → 杠杆 ≤ 8x

盈亏处理：

亏损：从备用金中补足亏损额，确保下次开仓仍是1份完整资金。

盈利：将利润部分从交易账户中转出至“利润储备池”。

8. 数据解读指南
多时间框架分析：

1H/4H： 用于判定“币种阶段”和“大级别趋势”。

15min： 核心交易图表，用于寻找“企稳拐点”。

5min： 用于精确寻找入场点。

关键技术指标：

EMA： 21 EMA 和 55 EMA，用于判断趋势方向与动态支撑。

Volume： 突破时需放量，回调时应缩量。

ATR： 用于评估合理的止损幅度。

资金费率： 正值但不过高（<0.05%）为健康多头市场。
