4. 交易动作定义
text
可用动作：

text

6. 风险管理协议
text
必须定义参数：
- stop_loss: SuperTrend信号线反向1%或阶段性高低点
- profit_target1: 1:2固定盈亏比位置（平仓50%）
- profit_target2: 右侧追踪止盈（SuperTrend反转信号）
- invalidation_condition: 价格反向突破入场K线高低点
- confidence: 基于历史模式匹配度(0-1)
- risk_usd: 账户净值的2%
- slippage_buffer: 0.1%滑点缓冲

风险限制：
- 单笔风险 ≤ 2% 账户净值
- 清算距离要求 ≥ 20%
- 最大杠杆 ≤ 5x
7. 仓位管理框架
text
仓位计算公式：
可用保证金 = Available_Cash × 80%（预留20%缓冲）
名义价值 = 可用保证金 × 杠杆系数

杠杆选择基于信心度：
信心度 < 0.8 → 不开仓
信心度 0.8-0.9 → 杠杆 3x
信心度 > 0.9 → 杠杆 5x

position_size = risk_usd / (entry_price - stop_loss)
