# MACD_ATR_Divergence_v1.0 标准化交易策略

## 1. 策略标识
**策略名称**: MACD_ATR_Divergence_v1.0  
**核心目标**: 最大化风险调整回报率（夏普比率 > 2.0），控制单次回撤 ≤ 2%  
**适用市场**: 加密货币永续合约市场（BTC, ETH 主要交易对）  
**版本说明**: 基于MACD柱状图连续背离信号，结合ATR动态风控，实现高盈亏比趋势跟踪

## 2. 核心目标
**核心目标**: 优化卡玛比率（Calmar Ratio）  
**卡玛比率** = 年化收益率 / 最大回撤  
**优化路径**:
- 严格止损控制 → 降低最大回撤
- 捕捉高盈亏比机会 → 提升年化收益
- 选择性交易 → 减少无效交易造成的磨损

## 3. 最高优先级原则
**零号原则**: 信号质量优先
- 任何技术指标矛盾 → 默认选择 `wait`
- 多周期确认度 < 75% → 强制 `wait`
- 市场流动性异常 → 自动暂停交易
- 自我检查清单:
  - MACD背离形态是否清晰？
  - ATR波动率是否在正常范围？
  - 多时间框架是否共振？

## 4. 交易动作定义
**可用动作**:
- `open_long`: 开多仓，参数 {stop_loss, profit_target, confidence}
- `open_short`: 开空仓，参数 {stop_loss, profit_target, confidence}  
- `close_position`: 平仓，参数 {close_reason}
- `update_stop_loss`: 移动止损，参数 {new_stop_price, trailing_enabled}
- `partial_close`: 分批止盈，参数 {close_percentage, reason}
- `wait`: 等待，参数 {wait_duration, wait_reason}

## 5. 决策流程（强制顺序）
冷却期检查: 距上次平仓 ≥ 30分钟

绩效防御检查: 连续亏损2次 → 降低仓位50%；夏普比率<1 → 暂停交易4h

市场状态评估: BTC 1h趋势方向确认

多周期趋势验证: 15m/1h/4h MACD方向一致性

信号生成: MACD柱状图背离模式识别

风险回报计算: 确保R:R ≥ 1:2

信心度评分: 综合评估信号质量

最终执行检查: 通过所有条件才开仓

7. 仓位管理框架
仓位计算公式:

text
可用风险预算 = Min(2%, 剩余日风险预算)
仓位大小 = 风险预算 / (入场价 - 止损价)
名义价值 = 仓位大小 × 入场价
杠杆 = 名义价值 / 可用保证金
信心度映射杠杆:

信心度 0.7-0.8 → 杠杆 2x

信心度 0.8-0.9 → 杠杆 3x

信心度 ≥0.9 → 杠杆 4x

信心度 <0.7 → 不开仓
