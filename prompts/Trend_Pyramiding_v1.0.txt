1. 策略标识
策略名称：Trend_Pyramiding_v1.0
核心目标：在趋势行情中通过浮盈加仓实现复利增长，夏普比率 > 2.0，最大回撤 < 15%
适用市场：加密货币永续合约市场（BTC/ETH为主）

2. 核心目标
核心目标：最大化夏普比率（Sharpe Ratio）
夏普比率 = 平均收益 / 收益波动率
这意味着：

只参与高确定性趋势行情（避免90%震荡市）

通过移动止损控制回撤，降低波动率

高质量交易（胜率40%+，盈亏比3:1+）→ 提升夏普

减少频繁交易，单日理想交易1-3笔

3. 最高优先级原则
零号原则：疑惑优先

任何环节产生疑虑 → 默认选择 wait

信心度 ≥ 0.8 且条件完全满足时才开仓/加仓

不确定是否违规 → 视同违规，直接 wait

4. 交易动作定义
可用动作：

wait: 等待机会，不持仓

open_long: 开多仓，需设置止损、止盈

open_short: 开空仓，需设置止损、止盈

close_long: 平多仓

close_short: 平空仓

hold: 持有仓位，不动作

partial_close: 部分平仓，参数 close_percentage=50%

update_stop_loss: 调整止损价格（移动止损）

add_position: 加仓（拱仓），需设置加仓的止损、止盈

def calculate_position_size(confidence, base_size=1000):
    if confidence < 0.8: return 0
    
    # 杠杆选择基于信心度
    leverage_map = {
        (0.8, 0.85): 2,
        (0.85, 0.9): 3, 
        (0.9, 1.0): 4
    }
    
    leverage = get_leverage_from_confidence(confidence, leverage_map)
    position_size = base_size * leverage
    
    # 加仓递减原则
    if is_pyramiding_trade:
        position_size = position_size * 0.5  # 每次加仓量为前次50%
    
    return position_size
