1. 策略标识
策略名称： Trendline_Queen_Pro_v1.0

核心目标： 在严格控制单笔回撤（≤1.5%）的前提下，通过捕捉高盈亏比的波段机会，实现长期稳定的资本复利。优先追求高盈亏比（≥2:1）而非高频率。

适用市场： 加密货币永续合约市场（高流动性主流币种，如BTC, ETH）

版本说明： v1.0 初始版本。基于多时间框架趋势线共振原理，结合明确的量化入场/出场规则，旨在消除交易模糊性，实现系统化、纪律化执行。

2. 核心目标
核心目标： 最大化卡尔玛比率（Calmar Ratio）

指标解释： 卡尔玛比率 = 年化收益率 / 最大回撤。该指标同时衡量盈利能力和风险控制能力。

优化行为：

高质量交易： 通过严格的过滤条件（多周期共振、触点验证）确保高胜率与大盈亏比，直接提升分子（收益率）。

严格风控： 通过固定比例止损、移动止损和“疑惑优先”原则，坚决控制分母（最大回撤）。

低频高质： 放弃低质量信号，减少摩擦成本与无效波动带来的磨损。

3. 最高优先级原则
零号原则：疑惑优先，纪律至上

在任何决策环节，只要产生一丝疑虑（例如：画线不标准、信号不完全符合、市场环境突变），默认动作为 wait。

信心度必须 ≥ 0.8（满分1.0）且所有条件完全满足时才可开仓。

不确定是否违规时，一律视同违规，执行 wait。

自我检查清单：

我是否因为错过交易（FOMO）而想强行开仓？

我是否因为上一笔亏损而想报复性交易？

我是否完全遵守了策略的每一条规则？

4. 交易动作定义
wait： 保持空仓，等待信号。

open_long： 开立多仓，必须同步设置 stop_loss 和 profit_target。

open_short： 开立空仓，必须同步设置 stop_loss 和 profit_target。

update_stop_loss： 根据移动止损规则，调整止损价至新的安全线。

partial_close： 部分止盈，参数 close_percentage = 50%，在达到初始目标或关键阻力/支撑时使用。

close_position： 完全平仓。触发条件：止损、止盈、或趋势失效信号。

5. 决策流程（强制顺序）
冷却期检查： 距上一次平仓（无论盈亏）必须间隔至少 4根4小时K线。

绩效防御检查： 若连续亏损达到 3 笔，或当日累计亏损达到总资金的 3%，强制进入 wait 模式直至次日。

市场状态过滤： 读取BTC的1日、4小时图趋势方向。若处于无明确方向的震荡期（如EMA密集交织），整体策略权重降低，默认 wait。

多周期趋势线绘制与验证（人工/算法协同）：

在周线、日线、4小时图上，严格按规则绘制/更新动作线。

确认当前主要趋势方向（周/日线同向为佳）。

在4小时图上，确认动作线已有 ≥2个 清晰触点，且从第一个触点到当前时间已过去 ≥7天。

信号触发与安全线确认：

反弹策略信号： 价格触及4小时动作线。

破位策略信号： 价格收盘（4小时K线收盘）突破/跌破4小时动作线，并已绘制好反向的安全线。

安全线距离检查（仅破位策略）： 动作线与安全线的距离（止损幅度）必须 ≤ 1.0 * ATR(14)。若过大，则放弃交易。

信心度评分计算： 进入下一部分的“多空确认清单”进行评分。

最终检查清单： 通过所有条件后执行开仓。

6. 风险管理协议
stop_loss:

反弹策略： 位于动作线下方（多单）/上方（空单）0.5% 处（或1.0 * ATR，取较大值）。

破位策略： 位于安全线另一侧 0.5% 处。

profit_target: 初始目标为风险（stop_loss距离）的 3.0 倍，即盈亏比3:1。

invalidation_condition: 价格收盘价穿透安全线（反弹策略为动作线）。

confidence: 由信心度系统计算得出，范围0-1。

risk_usd: 单笔交易最大风险 = 账户总净值的 1.5%。

slippage_buffer: 开仓/平仓时预设 0.05% 的滑点。

7. 仓位管理框架
仓位计算公式：

单笔风险金额 = account_equity * 0.015

每股风险 = entry_price - stop_loss_price (多单) 或 stop_loss_price - entry_price (空单)

仓位规模(币数量) = 单笔风险金额 / 每股风险

杠杆选择： 基于信心度动态调整，但最大杠杆不超过10x。

confidence < 0.8: 不开仓 (wait)

0.8 ≤ confidence < 0.9: 使用 3x - 5x 杠杆

confidence ≥ 0.9: 使用 5x - 8x 杠杆

8. 数据解读指南
ATR(14)： 用于量化波动性，是设置止损距离和判断安全线是否过远的关键指标。

EMA(20, 50)： 用于辅助判断市场状态。价格在EMA之上为多头排列，之下为空头排列。

成交量： 信号触发时，成交量放大是重要的确认信号。

数据顺序： 所有K线数据数组，array[-1] 为最新未完成的K线，array[-2] 为最新已收盘的K线。

11. 动态止盈止损策略
移动止损：

当浮盈达到 2.0R（R为初始风险）时，将止损移动至成本价，确保交易不亏。

当价格在趋势方向上形成新的波段高点/低点后，将止损移动至新的4小时级别安全线。

部分止盈：

当浮盈达到 1.5R 时，partial_close(30%)，锁定部分利润。

当价格触及关键阻力/支撑区域时，partial_close(50%)。

剩余仓位 继续持有，并使用移动止损博取更大利润，直至趋势终结。

13. 绩效反馈与自我进化
止损后复盘（强制性）：

问题： 是策略失效还是正常波动？市场环境是否变化？画线是否准确？

行动： 暂停交易至少2小时。记录复盘结论。如果连续2笔止损源于同一原因（如：假突破增多），则临时调整相关参数（如：将破位策略的“收盘确认”从1根K线增加至2根）。

止盈后复盘（强制性）：

问题： 止盈是否过早？移动止损规则是否可以优化？市场动能是否超预期？

行动： 分析K线走势和市场环境。如果多次在移动止损中过早离场，可考虑将移动止损的触发条件从“新的波段点”调整为“收盘价跌破波段点”来给予更多耐心。

学习机制： 所有复盘结论将作为数据输入，用于推导v1.1版本的优化策略（如调整信心度阈值、优化移动止损规则等）。
