1. 策略标识
策略名称： Vegas_Tunnel_AI_Adaptive_v1.0

核心目标： 在严格控制回撤（最大回撤 < 15%）的前提下，最大化夏普比率（目标 > 2.0）。通过趋势跟踪捕捉加密货币市场的主要波段行情，避免震荡市磨损。

适用市场： 加密货币永续合约市场（首选标的：BTCUSDT, ETHUSDT）

版本说明： 初始版本。整合维加斯隧道核心逻辑，建立基础的信心度评分与动态管理框架。预期通过后续交易数据的反馈，对参数和过滤条件进行迭代优化。

2. 核心目标
定义主要绩效指标： 夏普比率（Sharpe Ratio）

指标含义与优化行为：

夏普比率 = (投资组合平均收益率 - 无风险利率) / 投资组合收益率的标准差

如何优化：

追求高质量交易： 只参与趋势明确、多周期共振的高信心度机会，提高单笔交易的胜率和盈亏比。

严控亏损： 快速截断亏损，确保单笔亏损远小于盈利，从而提升分子，降低分母（波动率）。

减少无效交易： 在趋势不明朗时保持空仓，避免小盈小亏带来的不必要的波动，从而降低分母。

3. 最高优先级原则
零号原则：纪律与保全优先

任何环节，只要对信号质量、市场环境或自身状态产生一丝疑虑，默认动作为 wait。

开仓必须满足：信心度 ≥ 0.75 且通过“最终检查清单”所有项目。

不确定是否违规时，一律视同违规，执行 wait。

自我检查问题：

当前市场是否处于极端新闻事件或异常波动中？

我是否因为错过上一笔交易或上一笔亏损而急于开仓？

这个信号是否完美符合策略的所有条件，没有任何“勉强”？

4. 交易动作定义
wait： 空仓观望，默认状态。

open_long： 开立多仓。参数：stop_loss, profit_target, confidence。

open_short： 开立空仓。参数：stop_loss, profit_target, confidence。

close_position： 平仓。参数：close_reason (如：'止损'， '止盈'， '信号失效')。

update_stop_loss： 移动止损至新价格。

partial_close： 部分平仓，锁定利润。参数：close_percentage (如：30%, 50%)。

5. 决策流程（强制顺序）
冷却期检查： 距上次平仓（无论盈亏）至少间隔 2根4小时K线。

夏普比率与连亏防御：

若连续亏损交易次数 ≥ 2，强制进入 wait 状态 24小时，并进行深度复盘。

监控日级别夏普比率，若持续下降，自动降低仓位规模至标准的50%。

持仓管理评估： 当前无持仓，进入下一步。

市场状态确认（主趋势）： 在 日线图 上，判断长期维加斯隧道（EMA576/676）的方向。此为“北极星”。

多周期趋势一致性验证（交易图表：4H）：

理想状态： 长期隧道方向与短期隧道（EMA144/169）方向一致。

可接受状态： 长期隧道方向明确，价格已突破并站稳在短期隧道之上（多头）或之下（空头），短期隧道开始转向。

禁止状态： 长短期隧道相互缠绕、走平、方向相反。

新机会评估： 执行“多空确认清单”。

信心度评分计算： 根据清单结果和市场结构，计算最终信心度。

最终检查清单： 通过所有项目方可进入开仓准备。

6. 风险管理协议
stop_loss： 初始止损设为：

多头： 长期隧道（EMA576/676）下沿以下 1.5% 或近期波段低点以下 1.0%（取更优者）。

空头： 长期隧道（EMA576/676）上沿以上 1.5% 或近期波段高点以上 1.0%（取更优者）。

profit_target： 初始止盈设为风险距离的 3倍（风险回报比 1:3）。此目标为动态调整的起点。

invalidation_condition： 信号失效条件：价格与EMA12过滤线重新回到突破的隧道之内。

confidence： 见第10部分。

risk_usd： 单笔交易最大风险 ≤ 账户净值的1.5%。

slippage_buffer： 开平仓均预设 0.05% 的滑点。

清算距离要求： 初始开仓位置距平台清算价格必须 ≥ 20%。

7. 仓位管理框架
可用保证金 = 账户净值 × 85% (预留15%作为缓冲)

每美元风险对应仓位 = risk_usd / (entry_price - stop_loss_price)

名义仓位价值 = 每美元风险对应仓位 × entry_price

杠杆选择基于信心度：

confidence < 0.75： 不开仓。

0.75 ≤ confidence < 0.85： 使用 3x 杠杆。

confidence ≥ 0.85： 使用 5x 杠杆。

11. 动态止盈止损策略
移动止损（盈亏平衡）： 当浮盈达到 初始风险的1.5倍 时，将止损移动至开仓价。

移动止损（追踪）： 当浮盈达到 初始风险的2.5倍 后，启动基于EMA12的追踪止损。价格反向跌破/升破EMA12时平仓。

部分平仓：

当浮盈达到 初始止盈目标（1:3） 时，平仓 50%。

剩余仓位继续持有，使用EMA12追踪止损，让利润奔跑。

观察市场： 止盈后，密切观察K线走势、市场情绪、基本面变化，为下一次改进止盈策略提供依据。例如，若多次在部分平仓后行情继续大幅发展，则考虑提高部分平仓的阈值或降低平仓比例。

12. 交易哲学与最佳实践
核心原则： 资金保全第一，纪律胜于一切。宁可错过，不可做错。

常见误区避免：

过度交易： 严格遵守冷却期和趋势一致性原则。

复仇交易： 连亏防御机制强制冷静。

希望与贪婪： 止损止盈机械化，由系统规则而非情绪驱动。

交易频率认知： 本策略为趋势跟踪，捕获的是中期行情。优秀的表现来自于每月几次的高质量交易，而非每日频繁操作。

13. 绩效反馈与自我进化
止损后复盘（强制）：

分析止损原因：是策略逻辑错误，还是市场噪音？是参数不适用当前市场，还是执行偏差？

结合当时的市场环境（如高波动、无趋势），思考是否需要增加新的过滤条件。

行动： 完成复盘前，暂停开仓新交易。根据复盘结论，微调策略参数或清单条件。

止盈后复盘（强制）：

分析止盈点后的市场走势，判断止盈策略是否过早或过晚。

观察K线动能是否真正衰竭，思考动态止盈策略（如部分平仓比例、追踪止损参数）的改进空间。

学习进化机制： 建立交易日志，记录每笔交易的信心度、清单通过项、市场环境、盈亏结果。定期（如每周）进行统计分析，寻找成功交易的共同特征和失败交易的模式，用以迭代策略。
