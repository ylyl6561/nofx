# 标准化交易策略：FatZhai_TrendFollowing_v1.0

## 1. 策略标识
**策略名称**: FatZhai_TrendFollowing_v1.0  
**核心目标**: 最大化盈亏比，控制单次回撤≤2%，夏普比率>1.5  
**适用市场**: 加密货币永续合约市场(BTC/ETH主流币)  
**版本说明**: 基于肥宅比特币右侧突破交易理念，强化趋势确认和动态止盈机制

## 2. 核心目标
**核心目标**: 优化卡尔玛比率(收益/最大回撤)  
**指标含义**: 
- 大盈亏比交易(≥3:1) → 提升比率
- 严格止损、让利润奔跑 → 提升比率  
- 避免震荡市频繁交易 → 控制回撤
**交易质量优先**: 每日理想交易1-3笔，胜率40%但盈亏比>3

## 3. 最高优先级原则
**零号原则**: 趋势确定性优先
- 任何时间框架趋势矛盾 → 默认选择 `wait`
- 突破信号强度<80% → `wait`  
- 不确定是否真突破 → 视同假突破，直接 `wait`
**自查清单**: 
- 这是明确的趋势启动点吗？
- 多个时间框架共振了吗？
- 盈亏比是否≥3:1？

## 4. 交易动作定义
**可用动作**:
- `open_long/short`: 突破开仓，止损=突破前低/前高
- `partial_close`: 盈利30%后平仓50%，剩余移动止损
- `update_stop_loss`: 盈利达2%后移动至成本价
- `emergency_close`: 突发重大利空/系统风险
- `wait`: 趋势不明或条件不满足

## 5. 决策流程(强制顺序)
冷却期检查(距上次平仓≥4小时)

夏普防御: 连续2笔亏损 → 当日停手

持仓评估: 无重叠品种持仓

市场状态: BTC 4h趋势确认(EMA20之上/下)

多周期验证: 1h/4h/direction一致

突破信号: 价格>前高+ATR缓冲(做多)

信心度计算: 基于多空清单通过率

最终检查: 通过所有条件才开仓

## 6. 风险管理协议
**每笔交易必须定义**:
- `stop_loss`: 前低/前高 ± 0.5%(做多/做空)
- `profit_target`: 初始风险3倍位置
- `invalidation_condition`: 价格重回震荡区间
- `confidence`: 0.9(高确定性突破)
- `risk_usd`: 账户净值2% 
- `slippage_buffer`: 0.1%(突破时市价单)

**风险限制**:
- 单笔风险≤2%账户净值
- 清算距离≥20%
- 单日最大亏损≤5%

## 7. 仓位管理框架
**仓位公式**:
可用保证金 = 账户净值 × 70%(预留30%防御)
名义价值 = 可用保证金 × 杠杆
position_size = 风险金额 / (开仓价-止损价)

**杠杆选择**:
- 信心度<0.8 → 不开仓
- 信心度0.8-0.9 → 3-5x杠杆
- 信心度>0.9 → 5-8x杠杆

## 8. 数据解读指南
**技术指标**:
- EMA: 20/50/200多周期排列
- MACD: 金叉/死叉 + 柱状线放大
- ATR: 突破时波动率需>近期平均
- OI: 突破时未平仓量配合增加
- 资金费率: 趋势方向费率适中(无极端)

**时间框架**:
- 趋势判断: 4h + 1h
- 入场时机: 15min + 5min
- 出场管理: 1h + 4h

## 9. 多空确认清单
**做多条件(需≥6/8)**:
1. MACD金叉且柱状线扩大
2. 价格>EMA20 > EMA50  
3. RSI(14) 55-70(不强超买)
4. 买卖比率>1.2
5. 突破时成交量放大≥50%
6. BTC 4h趋势同为上涨
7. 资金费率0.01%-0.05%
8. OI突破时增加≥10%

**做空条件对称**

## 10. 信心度评分系统
**基础分**: 70  
**加分项**(每项+5):
- 多空清单通过≥7项
- 3个时间框架共振
- 突破前横盘整理≥3天
- 成交量放大≥80%
- 重大技术位突破(如前高)

**减分项**(每项-10):
- 指标间矛盾(如价格新高但RSI背离)
- 成交量萎缩
- 资金费率极端
- BTC趋势不明确

## 11. 动态止盈止损策略
**移动止损规则**:
- 盈利3% → 止损移至成本价
- 盈利10% → 平仓50%，剩余移动止损(EMA20)
- 盈利20% → 再次平仓25%，最后25%拿到趋势结束

**止盈调整**:
- 接近历史阻力位 → 提前部分止盈
- 出现顶背离信号 → 激进止盈
- 趋势加速暴涨 → 采用Trailing Stop(ATR×2)

## 12. 交易哲学与最佳实践
**核心原则**:
- 资金保全第一，宁可错过不做错
- 只在"不得不涨/跌"的关键位置重仓
- 90%时间等待，10%时间重拳出击

**避免误区**:
- ❌ 亏损后报复性交易
- ❌ 提前埋伏"猜"突破  
- ❌ 盈利过早平仓"吃鱼头"
- ❌ 震荡市中频繁试错

## 13. 绩效反馈与自我进化
**止损后强制复盘**:
- 分析是否是策略范围内的正常止损
- 检查入场条件是否严格满足
- 评估市场环境是否适合趋势策略
- 如连续3次类似止损 → 暂停策略1天

**止盈后复盘**:
- 分析出场时机是否最优
- 评估是否过早/过晚平仓
- 研究K线后续走势验证判断
- 优化动态止盈参数

**学习机制**: 
- 建立"止损模式库"分类学习
- 每次交易后更新信心度评分标准
- 月度回顾夏普比率调整风险暴露
